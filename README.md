📱 Kapsulez App – Digital Pharmacy & Doctor Booking Platform
📌 Project Overview

Kapsulez App is a responsive, mobile-first web application designed for a local pharmacy to digitally manage medicine ordering, doctor appointment booking, and customer engagement.
The application provides an intuitive interface for customers to browse offers, consult doctors, place medicine orders via WhatsApp, and access store information seamlessly.

This project focuses on practical implementation, user experience, and real-time interaction, simulating a production-ready digital healthcare solution.

🎯 Problem Statement

Local pharmacies often rely on manual processes for medicine orders and appointment coordination, leading to delays and inefficiencies. Customers also lack a centralized platform to:

View available doctors and consultation fees

Access current medicine offers

Place quick orders without complex registration

Leave feedback or reviews

The Kapsulez App addresses these challenges by providing a simple, fast, and user-friendly digital interface that integrates ordering and booking through WhatsApp.

Styling & UI: CSS Variables, Flexbox, Grid, Animations

Icons: Font Awesome

Fonts: Google Fonts (Poppins)

Maps Integration: Google Maps Embed

External Integration: WhatsApp Click-to-Chat

⚙️ Application Flow

User lands on the Home screen

Navigates to Doctors / Offers / Store sections using bottom navigation

Selects department → doctor → views details

Books appointment or orders medicines via WhatsApp

Views store details, reviews, and submits feedback
